# Customer-Churn-Prediction
This is a predictive model used to predict whether or not a customer will leave or stay.
I obtained the dataset from kaggle, used XGBOOST and LGBM as the models for fitting and evaluation and applied hyperparameter tuning to optimize the models.
For data preprocessing, I applied ADASYN to deal with imbalanced data, applied one hot encoding for the categorical features and applied scaling to standardize the data.
